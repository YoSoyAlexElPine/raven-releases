# Raven

Aplicación Android para extraer paradas de capturas de reparto y preparar su envío a Circuit.

Este repositorio reúne las versiones oficiales de Raven y sus notas de cambios.

## Descargas

Las versiones listas para instalar se publicarán en [Releases](https://github.com/YoSoyAlexElPine/raven-releases/releases).

Todavía no se ha publicado un APK de distribución.
